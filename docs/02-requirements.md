# 需求演进（提示词整合）

> 把多轮口语化反馈**去重、归类**成可执行的技术条目。左侧是诉求，右侧是落地结果。

---

## 第 1 轮 · 立项

**诉求**
- 高精度 Q 版女仆，**不要简化、不要粗糙方块堆积**
- 严格按参考图（7 张：正/侧/背/顶/底 + 服装分解）
- 全部程序化，**不引用电脑里任何现成资产**

**落地**
- 1 m 高、头占 39.5% 的手办比例；全程 Python 生成，零外部模型/贴图。
- 建立 `mprop.py` 作为唯一数值源，比例从参考图逐项量取。

---

## 第 2 轮 · 造型修正

**诉求**
- 发箍是**小一圈戴在头上**的，不是头冠
- 修穿模；头发要改；袜子、内裤要改；**没有脚**
- 最后要出 1.5 分钟介绍视频

**落地**
- 头饰改为贴头窄带 + 沿头部表面立起的褶边。
- 新增脚掌（鞋楦断面）+ 脚踝柱；袜子按小腿半径拟合并延长进鞋内。
- 内裤改三角裤收口，收到裙摆内。

---

## 第 3 轮 · 结构重构

**诉求**
- 脚要有**脚趾**
- 袜子要**套在脚上**，不能穿模
- 内裤要**三角包裹**
- 头箍要**半圆月牙**、**加厚**
- 头发学参考图（**不要一堆小刘海，要一整块**）
- 手掌/手臂错位；手和裙子穿模
- 围裙要**一整个整体**，别拆成几件
- 手臂和袖口穿模

**落地**
- 脚：10 组断面 + **5 根脚趾** + 脚踝柱。
- 袜：脚/腿表面**偏移壳**（脚 +2 mm、小腿 +5 mm）。
- 内裤：腰 0.345 / 裆 0.195 / 腿口 0.283，底部压合封口。
- 头饰：开放月牙（±106°），宽 0.021、厚 8 mm。
- 刘海：**删掉 16 根分离发片 → 一整片连续曲面**。
- 手：方向取前臂末端切线（原来差 35°，这就是"错位"的根因）。
- 围裙：胸片→腰带→裙摆**一张连续曲面**并 join 成单物体。
- 袖口：袖扣做成贴在袖口外表面的球。

## 第 4 轮 · 工作流事故

**诉求**
- "你改的文件到底放哪了？打开还是旧的"
- "我改过的鞋子大小和手掌位置你又换回去了"

**根因 / 落地**
- 根因 1：用户 Blender 里是内存旧数据 → 需 `File → Revert`。
- 根因 2：**我用"源码重建"覆盖了用户手工微调的 .blend**。
- 落地：从用户自动保存 `D:\blender-temp\*_autosave.blend` 里逐物体比对，恢复出用户的确切数值
  （鞋缩放/位移、手位移、脚 Y 缩放、删除的耳朵与 Lock_1），并**固化进生成器**。
- 流程改正：**不再全量重建覆盖**，改为增量编辑既有 .blend。

---

## 第 5 轮 · 收尾与出片

**诉求**
- 光影照参考图；自己做背景；出渲染动画
- 横屏、发 B 站、**不要音乐**、**加字幕**、**45 秒** → 后改 **60 秒**
- **每个角度都要看到**、近景远景、**俯视 + 仰视**
- 相机不要穿模
- 最后：整合文档、清理无用文件、准备上 GitHub

**落地**
- 影棚版（无缝绕幕）与展示版（霓虹 HDRI + 展台 + 发光环）两套光。
- 60 秒 / 1280×720 / 24fps / 无音轨 / 中文 ASS 字幕烧入。
- **15 机位巡览**：全身远景 → 各部位特写 → 俯视 → 仰视 → 收尾远景。
- 相机硬约束：`SAFE_R = RAD+0.30`、`FLOOR_Z = 0.16`，逐帧钳位。
- 展台顶面移到 z=0，解决"脚陷进台子"。

## 需求 → 技术映射速查

| 口语诉求 | 技术动作 |
|---|---|
| "不要方块堆积" | 全部曲面放样 + Catmull-Rom 半径，无 cube 拼接 |
| "发箍像月牙、加厚" | 开放圆弧路径 + 沿表面法向偏移 + solidify 8 mm |
| "一整块刘海" | 单张连续 grid 曲面替换 N 根独立发片 |
| "围裙一体" | 单一参数化曲面 + join 单一物体 |
| "袜子在脚上" | 表面偏移壳（padding shell）而非独立圆筒 |
| "每个角度" | 逐帧机位节拍表（方位角 × 仰角 × 半径 × 焦距） |
| "不要穿模" | 包围盒推导的 SAFE_R / FLOOR_Z 硬钳位 |
