# 完整建模流程

> 目标：在**空场景**里用 Python 生成一个 1 m 高的 Q 版女仆，全部几何程序化，
> 零外部模型 / 零贴图。所有尺度以 `H = 1.00 m` 归一化。

---

## 0. 总体管线

```
mprop.py            比例 / 配色常量（唯一数值源）
   │
   ├─ mhead.py      头部 + 五官 + 眼睛          ┐
   ├─ mhair.py      发帽 + 刘海 + 鬓角          │  各模块 return 物体列表
   ├─ mbody.py      躯干 / 四肢 / 手 / 脚       │  统一由 build.py 装配
   ├─ mcloth.py     服装全家桶                  │
   └─ lib/*.py      荷叶边 / 蝴蝶结 / 鞋 / 手   ┘
   │
   ├─ build.py      装配 → 集合分层 → 灯光相机 → 渲染 → 存盘
   └─ mcore.py      基元库（放样 / 旋转 / 管 / 带 / 球）+ 材质 + 渲染工具
```

**关键原则**：

1. **`mprop.py` 是唯一的数值源头**。改比例只改这里，其余模块只引用。
2. **每个部件都是 `(verts, faces)` 生成器**，最后统一 `C.new_obj()`。
3. **贴面类细节（眼/眉/嘴/腮红）必须共形到解析曲面**，否则会浮空或陷进去。

## 1. 基元层（`mcore.py`）

| 基元 | 用途 | 要点 |
|---|---|---|
| `grid(fn, nu, nv, close_u)` | 参数曲面（裙、围裙、领、袜） | `fn(u,v)→(x,y,z)`，`close_u` 决定周向是否闭合 |
| `loft(rings)` | 放样（头、躯干、手臂） | 环间顶点数必须一致 |
| `revolve(profile)` | 旋转体（纽扣、袖扣） | |
| `tube(pts, radii)` | 管状（手臂、腿、手指） | **平行移动标架**，避免扭转 |
| `ribbon(pts, w, t)` | 带（背带、蝴蝶结带） | 需要稳定的 `normal` |
| `sphere(...)` | 球（腮红、珍珠、眼白） | |
| `apply(mod)` / `add_solidify` / `add_subsurf` | 加厚与细分 | **solidify 的 `even_offset` 在极点会撕裂**，见 §7 |

材质 `mats.all_mats()` 全部节点化生成：皮肤（位置驱动腮红）、头发（Z 渐变 + 清漆）、
虹膜（顶点色）、深蓝布（sheen）、白棉、缎带、皮革、珍珠、鞋底。

## 2. 头部（`mhead.py`）

### 2.1 头形
超椭圆截面放样，`_PROF` 表给出 z ∈ [0.600, 0.968] 的 `(rx, ry, q, yc)`：

```
x = rx·sinθ
y = yc ∓ ry·(1 − |sinθ|^q)^(1/q)
```

`q` 随高度变化：眼高处 **q ≈ 4.2**（前脸被压平），下颌处收敛到圆。
这样得到的脸颊平、太阳穴圆，是 Q 版脸的关键。

### 2.2 软体积与中线剖面
`_bump(x, z)` 用高斯叠加鼻头、颧骨、眼窝隆起、下巴、眉弓；
中线 `profile(z)` 叠嘴唇 / 人中 / 下巴沟。
所有五官贴面都通过 `face_y(x, z)` 求值 —— **解析的同一张脸**，不可能错位。

### 2.3 眼睛堆栈（从内到外）
1. `_iris_disc`：虹膜圆盘，**逐顶点颜色**写入 `Col` 属性（上深下浅 + 边缘压暗），
   用 `ShaderNodeVertexColor` 驱动 —— 不用 UV、不用贴图，所以永不漂移。
2. 眼白 + 瞳孔 + 两个高光球（左上大、右下小）。
3. 上睫：厚黑片，外眼角起挑；下眼线：细黑片。
4. 红色点缀：上睫外侧 + 眼角。
5. 眉毛：细长贴面。
6. 嘴：ω 形小片。

**所有贴面统一 `C.orient_faces(ob, 1, -1)`** —— 法线必须朝 −Y（否则渲染成黑片）。

## 3. 头发（`mhair.py`）

- `rim_z(u)`：发帽下缘的**分叶**曲线（k=14），决定后颈/耳侧的长度。
- `hair_point(u, z, extra)`：核心采样函数 —— 给角度与高度，返回**头发表面点**（外扩 `extra`）。
  头饰、发片、鬓角全部复用它，保证贴合。
- 发帽：`grid` + `solidify(0.008)` + `subsurf`。
- 刘海：**一整片连续曲面**（170×48），下沿用 4 个大波浪；早期版本是 16 根分离发片，
  观感像"叶子"，已废弃。
- 鬓角：2 片细长发片，起点埋进发帽内部（避免出现"尖刺"）。

---

## 4. 身体（`mbody.py`）

- **手臂**：6 个控制点 → `polyline_resample(80)` → 全局 Catmull-Rom 半径曲线。
  逐段 `smoothstep` 插值会产生"箍痕"，必须用全局样条。
- **手**：腕部局部坐标建模（掌 4 圈环 + 4 指 + 拇指），
  放置时**手的方向必须取前臂末端切线**（否则错位，这是踩过的坑）。
- **脚**：10 组鞋楦式断面（heel→arch→toe），鞋底压平，**5 根脚趾**，
  脚踝柱塞进鞋口。
- **袜**：脚与腿的**偏移壳**，脚部 +2 mm、小腿 +5 mm，保证永不顶穿。

## 5. 服装（`mcloth.py`）

| 部件 | 做法 |
|---|---|
| 裙 | 9 叶折 `grid` + `SKIRT_RX/RY` 半径表，下摆 z=0.204 |
| 领 | 彼得潘领：内缘贴颈 `r=0.0318`、前中开口 24°、两侧圆角尖，`grid` + `solidify` |
| 袖 | 泡泡袖：沿二次贝塞尔放样 + 白翻边袖口（袖扣已按客户要求移除） |
| 肩荷叶边 | **已按客户要求移除**（早期为左右两条肩弧 `RF.build_ruffle`） |
| 围裙 | **一张连续曲面**：胸片→腰带→裙摆，按 z 参数化半宽表；荷叶边沿整圈外缘；与双肩带 **join 成单个物体** |
| 内裤 | `grid`（腰 0.345 / 裆 0.195 / 腿口 0.283）→ 顶部裁到 z=0.298 → 底部 Y 向压合 |
| 头饰 | 贴合颅顶的**厚半圆带**（±106°），宽 3.9 cm、厚 8 mm，上沿 11 瓣浅波浪 |
| 鞋 | `lib/shoe.py` 鞋楦；**鞋口前缘抬高**（`rim_drop_front` 0.075H）包住脚背 |
| 蝴蝶结 | `lib/bow.py`，结心贴腰带面（y=0.079） |

## 6. 渲染与展示

- 影棚版：无缝绕幕（`cyclorama`）+ 4 盏面光 + Standard 色彩管理。
- 展示片版：CC0 霓虹 HDRI + 金属展台 + 发光环 + 双色灯条。
- 相机巡览：**11~15 个机位节拍**，逐帧用 smoothstep 插值方位角 / 仰角 / 半径 / 焦距。
- **相机安全约束**（防穿模）：
  ```
  SAFE_R = RAD + 0.30     # 水平半径下限（RAD = 角色包围盒水平半径）
  FLOOR_Z = 0.16          # 相机高度下限
  ```
  每帧钳位，仰视镜头也不会钻地。

## 7. 踩过的坑（重要）

| 现象 | 根因 | 修法 |
|---|---|---|
| 材质全黑 | `mmat._new()` 删掉了 `OUTPUT_MATERIAL` 节点 | 保留输出节点并连 BSDF |
| 五官全黑 | 贴面法线朝 +Y | `orient_faces` 强制 −Y |
| 虹膜渐变反了 | 依赖 UV | 改逐顶点 `Col` 属性 |
| 头顶一条裂缝 | 发帽 `solidify(even_offset=True)` 在极点自交 | 关掉 `even_offset`，降到 0.008 |
| 手臂有箍痕 | 逐段 `smoothstep` 半径 | 全局 Catmull-Rom + 重采样脊柱 |
| 围裙炸成白片 | 半宽没乘带符号的 `u`，曲面退化成竖条 | `hw = f(z) * u` |
| 裙子重建后错位 | 脚本写死绝对路径 | 全部走 `ROOT` 相对路径 |
| 手工微调被覆盖 | 用「源码重建」覆盖了用户改过的 .blend | 改为增量：打开→改目标物体→存回 |
| 内裤底部镂空 | 生成的是两头通的筒 | 底部按高度压合 + 平面切割封口 |
| 相机钻地 | 仰视机位仰角过大 | `FLOOR_Z` 钳位 + 仰角收到 −18° |
| 人物陷进展台 | 展台 z 从 0 抬到 0.055，脚底在 0 | 展台顶面移到 z=0 |

---

## 8. 复现注意

- `build.py` 是**全量重建**：会覆盖输出 .blend。
- 若已有手工微调，用增量脚本：`open_mainfile → 只改目标 object → save_as_mainfile`。
- `%TEMP%` 一律重定向到项目临时目录，避免污染系统盘。
